# Scene Generation Contract

Audience: Local coding agents working on Manim scene generation, validation, and repair.

Purpose: Define the current scaffold and scene-body contract that governs generated Manim scenes.

## Ownership Split

The scaffold owns:

1. Imports.
2. Manim frame configuration.
3. Scene class definition.
4. `VoiceoverScene` inheritance.
5. Cached speech service setup.
6. `with self.voiceover(text=SCRIPT[...]) as tracker:`.
7. Slot markers.

The harness-generated body owns only:

```text
Python statements inside construct(self), inside the existing voiceover block.
```

The model must not output:

1. Imports.
2. Class definitions.
3. Function definitions.
4. Config assignments.
5. Scaffold markers.
6. `with self.voiceover(...)`.
7. Markdown fences, XML, explanations, or comments when the prompt forbids comments.

## Scaffold Source

The deterministic scaffold is generated by:

```text
scripts/scaffold_scene.py
```

Required scaffold structure includes:

```python
from narration_script import SCRIPT
self.set_speech_service(get_speech_service(Path(__file__).resolve().parent))
with self.voiceover(text=SCRIPT["<narration_key>"]) as tracker:
    # SLOT_START:scene_body
    ...
    # SLOT_END:scene_body
```

`harness_responses/parser.py` injects generated `scene_body` between `# SLOT_START:scene_body` and `# SLOT_END:scene_body`.

## First-Pass Validity Target

First-pass `build_scenes` output should be valid enough to pass all deterministic gates without invoking `scene_repair`.

Current runtime still supports repair loops. That support is a containment mechanism, not the desired generation contract.

## Validation Gates

`scripts/build_video.sh` currently validates each scene with:

1. Scaffold/template signature checks.
2. Python syntax checks.
3. Static import/API checks.
4. Voiceover sync checks.
5. Timing-budget analysis.
6. Placeholder/demo-content checks.
7. `manim render --dry_run`.

Scene QC later repeats deterministic runtime dry-runs over built scenes.

## Repair Behavior

When validation fails, `build_video.sh` may call:

```text
scene_repair
```

Repair flow:

1. Reset scene from scaffold.
2. Preserve prior slot body when possible.
3. Compose repair prompt with current scene, plan details, narration, and error context.
4. Inject repaired `scene_body`.
5. Re-run validation gates.

Repeated repair is expensive. Source-level fixes should reduce entry into this path.

## Manim API Risk Surface

Common first-pass failure sources:

1. Invalid Manim class, method, or animation names.
2. Unsupported keyword arguments such as unsupported `FadeIn` kwargs.
3. Deprecated animation names such as `ShowCreation`.
4. Invalid color objects or lists passed to Manim color APIs.
5. Missing `tracker.duration` timing.
6. Timing expressions that overrun cached narration.
7. Escaped HTML operators such as `&lt;` and `&gt;`.
8. Duplicate voiceover wrappers.
9. Placeholder scaffold content left in the slot.

Prompt, schema, parser, and deterministic validators should prevent these before runtime render where possible.

## Generated Artifact Boundary

Generated `scene_*.py` files are evidence by default. Fix the generation contract, scaffold, prompt, parser, or validator unless the user explicitly asks for a project-level containment patch.
